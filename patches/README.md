# patches/

本目录**不含补丁产物**，只保留说明。

## 为什么是空的

部署过程中对第三方组件（NapCat、AstrBot）打过一些本地适配补丁。
这些补丁是**针对本机环境的临时适配**，且涉及修改第三方分发物，
不适合放进公开仓库：

1. 补丁产物是从第三方程序中反编译/修改得到的文件，再分发涉及版权问题；
2. 具体改动内容与特定机器环境绑定，别人套用会出问题；
3. 其中部分改动会降低安全性。

## 需要复现时

自行针对原版组件做等效修改。`probe/` 目录下的脚本展示了
「定位哪个文件、找什么特征串」的方法，可以照着改。

## 本仓库实际做了什么改动（不含实现细节）

| 组件 | 改动性质 | 目的 |
|---|---|---|
| NapCat WebUI | 认证逻辑 | 本机单用户调试，免去每次登录 |
| AstrBot WebUI | 静态资源缓存策略 | 刷新页面能看到新前端 |
| WSL2 网络 | 代理绕过规则 | 让容器能访问宿主机的本地服务 |
