# 大肥鱼 QQ 机器人 · AI 画图功能搭建与接入指南

> 面向想给自己机器人加画图能力的人。本文讲清三件事：
> **怎么搭**（插件 + 接口 + 配置）、**群友怎么画图**、**机器人怎么自己 5% 概率画一张**。
> 基于本项目实际在跑的配置（2026-11-07 验证），不是纸上谈兵。

---

## 0. 一句话总览

```
群友发「画一只猫」/「/画图 一只猫」
        │
        ▼
AstrBot + dsh-imagegen 插件  ──►  OpenAI 兼容的 /images/generations 接口
        │                              （智谱 cogview / Agnes AI / pollinations 三选一）
        ▼
   图片发回群里（单独一条消息）

另外：机器人每次正常回复时，有 5% 概率把「当前群聊话题」随手画一张发出来。
```

**三个角色**：

| 角色 | 是什么 | 谁来提供 |
|---|---|---|
| AstrBot | QQ 机器人框架（装插件、接 QQ、管 LLM） | 开源，Docker 部署 |
| dsh-imagegen | 画图插件（意图识别、防刷、发图） | 本项目的 `data/astrbot/plugins/dsh-imagegen/` |
| 生图接口 | 真正把文字变图片的 API | 智谱 / Agnes AI / pollinations（免费） |

## 1. 准备工作

### 1.1 你需要的东西

1. 一台能跑 Docker 的机器（Windows + WSL2 也行，本项目就是这么跑的）
2. AstrBot 已经能正常聊天（LLM 通道配好）
3. 一个生图 API Key（三选一，见 1.2）
4. 本项目里的 `dsh-imagegen` 插件目录

### 1.2 生图接口三选一

| 后端 | 配置值 | 要不要 Key | 说明 |
|---|---|---|---|
| **智谱 BigModel**（本项目在用的） | `DSH_IMG_BACKEND=openai`<br>`DSH_IMG_API_BASE=https://open.bigmodel.cn/api/paas/v4`<br>`DSH_IMG_MODEL=cogview-3-flash` | 要 | 中文提示词原生支持，`cogview-3-flash` 便宜、快；备用 `glm-image` |
| Agnes AI | `DSH_IMG_API_BASE=https://apihub.agnes-ai.com/v1`<br>`DSH_IMG_MODEL=agnes-image-2.5-flash` | 要 | 插件默认值，海外模型，中文会自动翻成英文 |
| pollinations | `DSH_IMG_BACKEND=pollinations` | **不要** | 免费，按出口 IP 限流（约 1 张/45 秒），适合先试水 |

> 提示词建议：中文模型（cogview / glm-image / qwen-image…）直接写中文；
> 海外模型（flux / sdxl）插件会自动调用 LLM 把中文翻成英文（`DSH_IMG_TR_PROVIDER=auto`）。

## 2. 搭建步骤

### 2.1 放插件

把插件目录放进 AstrBot 的插件目录（容器里是 `/AstrBot/data/plugins/`）：

```
dsh-imagegen/
├── main.py            ← 插件主体（本文所有逻辑都在这里）
├── metadata.yaml
└── test_*.py          ← 可选，回测脚本
```

本项目的部署是把 Windows 侧 `data/astrbot/plugins/` 挂载进容器，
所以改 `D:\xml\dafeiyu\data\astrbot\plugins\dsh-imagegen\main.py` 即可。

### 2.2 配环境变量（`robot.env`）

关键项（其余都有默认值，不用全填）：

```ini
# ── 生图渠道 ──
DSH_IMG_BACKEND=openai
DSH_IMG_API_BASE=https://open.bigmodel.cn/api/paas/v4
DSH_IMG_API_KEY=<你的智谱 API Key>
DSH_IMG_MODEL=cogview-3-flash
DSH_IMG_FALLBACK=glm-image
DSH_IMG_SIZE=1024x1024
DSH_IMG_TIMEOUT=150

# ── 防刷 ──
DSH_IMG_COOLDOWN=50          # 同一会话两次生图最小间隔（秒）
DSH_IMG_CONCURRENCY=2        # 同时最多几张
DSH_IMG_KEEP=2592000         # 生成图保留 30 天，到期自动清理

# ── 统一画风（所有图都会追加这段）──
DSH_IMG_STYLE=cute chibi anime style, kawaii, flat colors, simple background
```

> ⚠️ **API Key 只放 `robot.env`，不要提交到仓库**（本项目 `.gitignore` 已排除）。

### 2.3 让配置生效（最容易踩的坑）

**`docker restart astrbot` 不会重读 `env_file`！** 必须重建容器：

```bash
cd /opt/dafeiyu        # 你的 compose 所在目录
docker compose up -d --no-deps --force-recreate astrbot
```

本项目 `docker-compose.yml` 里 napcat 用了
`ACCOUNT=${NAPCAT_ACCOUNT:?...}` 强制插值，而 `robot.env` 里没这个值，
直接 `up` 会报错。所以脚本里是从**正在跑的 napcat 容器**读出实际 QQ 号，
临时喂给 compose（不改文件、不重建 napcat，避免丢它的免登录补丁）：

```bash
ACCT=$(docker inspect -f '{{range .Config.Env}}{{println .}}{{end}}' napcat \
        | sed -n 's/^ACCOUNT=//p' | head -1)
env NAPCAT_ACCOUNT="$ACCT" docker compose up -d --no-deps --force-recreate astrbot
```

现成脚本：[deploy_imagegen_draw.sh](../dafeiyu-local/probe/deploy_imagegen_draw.sh)、
[recreate_astrbot.sh](../dafeiyu-local/probe/recreate_astrbot.sh)。

### 2.4 验证

```bash
docker logs astrbot --since 2m | grep "\[imagegen\] 已加载"
# 应打印：base=... model=cogview-3-flash ... auto=True concept=True/1800s
```

群里发 `/画图状态` 能看到渠道、模型、Key 是否配置、冷却与画风。

## 3. 群友怎么画图（三条触发路径）

插件把"要图"识别做成三层，从强到弱，专门对付便宜模型"嘴上答应画、实际不调工具"的毛病：

| 路径 | 触发方式 | 例子 |
|---|---|---|
| ① LLM 工具 | 模型规范调用 `generate_image` | 「画一只戴墨镜的橘猫」 |
| ② 兜底钩子 | 模型只回「在画了」但没真调工具时，插件自己识别意图出图 | 同上（模型的锅，插件兜底） |
| ③ 显式指令 | `/画图 <描述>`，**完全绕过模型** | `/画图 一只戴墨镜的橘猫` |
| ④ 主动概念图 | 群友**描述一个明确的视觉成品**（不是直接要图），机器人主动画草图并问「是不是这种感觉」 | 「我想要一个蓝色长发、有鲸鱼耳朵的角色」 |

**权限**：`/画图` 在 `dsh-acl` 的 `PUBLIC_CMDS` 里，**所有群友都能用**；
`画图状态` 是管理员指令。自然语言路径（①②③）同样对所有人开放。

> 意愿识别刻意做得保守：讨论已有图片、问「长什么样」、要视频/语音，都**不会**误出图。
> 日志会记「未触发出图」及命中了哪条信号，方便排查"有时候不生图"。

## 4. 机器人自己 5% 概率画图

### 4.1 行为

- 机器人**每次正常回复群消息**时，掷一次骰子，`5%` 命中就额外画一张图发出来；
- 画的是**当前群聊话题**：把群友原话 + 机器人接的话拼成提示词（例如「周末去露营 ｜ 机器人接话：带帐篷吗」→ 画一张露营场景）；
- 命中时在图片后附一句 `（顺手画了张图）`，可改；
- **失败完全静默**，不影响正常聊天；
- 与群友主动要图互相独立：本轮已经出过图就不再画第二张。

### 4.2 配置项（`robot.env`）

```ini
DSH_IMG_RANDOM_RATE=0.05         # 概率，0 = 关闭；0.1 = 10%
DSH_IMG_RANDOM_COOLDOWN=180      # 每个群两次随机出图的最小间隔（秒），防刷屏
DSH_IMG_RANDOM_MIN_CHARS=6       # 太短的消息不画（「嗯」「6」）
DSH_IMG_RANDOM_MAX_CHARS=120     # 太长的消息不画（刷屏长文）
DSH_IMG_RANDOM_PREFIX=把下面这段群聊内容画成一张图，抓住里面最具体的那个画面，不要画文字：
DSH_IMG_RANDOM_REPLY=（顺手画了张图）
```

### 4.3 不会乱画的几道闸（都在 `random_draw` 里）

1. 只处理 **群聊**，私聊不画；
2. 跳过 `/` 开头的指令；
3. 跳过本轮已有生图（`imagegen_done`）、主动发起（`dsh_initiate` / `dsh_proactive`）；
4. 跳过「用户明确在要图」的消息（交给路径 ①②③，避免一题两画）；
5. 长度门槛；
6. **独立冷却 180 秒** + **全局冷却 `DSH_IMG_COOLDOWN`** 双重限制；
7. 同一会话并发去重（`_random_inflight`）；
8. 掷骰子放在所有判断之后，不命中几乎零开销；
9. 生图整个包在 `try/except BaseException` 里，任何异常都只写日志。

### 4.4 主动概念图也放开了

默认 `AUTO_CONCEPT` 是关的，且只白名单 3 个群。本次改成**对全部群开放**：

```ini
DSH_IMG_CONCEPT_AUTO=1
DSH_IMG_CONCEPT_GROUPS=          # 留空 = 所有群；填具体群号 = 白名单；填 * = 全开
```

代码里把 `CONCEPT_GROUPS and gid not in CONCEPT_GROUPS`
改成 `CONCEPT_GROUPS and "*" not in CONCEPT_GROUPS and gid not in CONCEPT_GROUPS`，
空集合即全放行。概念图自带 1800 秒冷却，不会和随机生图叠加刷屏。

### 4.5 概率是怎么验证的

[pytest 风格的纯逻辑回测](../dafeiyu-local/probe/test_random_draw.py) 跑 10 万次采样：

```
[ok] 默认配置：rate=0.05 cooldown=180
[ok] 10 万次采样命中率 0.0498（4979/100000）
[ok] DSH_IMG_RANDOM_RATE=0 可关闭
[ok] 门槛：仅群聊/非指令/长度/已有生图/明确要图 均跳过
[ok] 两份源码均支持 CONCEPT_GROUPS 空/* = 全群放行
ALL PASS
```

## 5. 从零接入别人的机器人（最短抄作业版）

1. 装好 AstrBot（能用 LLM 聊天）。
2. 复制 `dsh-imagegen/` 到 `/AstrBot/data/plugins/`。
3. 申请一个生图 Key，往 `robot.env` 填 **2.2 节**那几行。
4. 加 4.2 / 4.4 节的随机生图与概念图开关。
5. `docker compose up -d --no-deps --force-recreate astrbot`（**别用 restart**）。
6. 群里发 `/画图 一只戴墨镜的橘猫` 看是否出图；再发 `/画图状态` 核对配置。
7. 观察一两天 `docker logs astrbot | grep imagegen`，用 `DSH_IMG_RANDOM_RATE` 调概率、
   用 `DSH_IMG_RANDOM_COOLDOWN` 调节奏。

**费用提示**：随机生图是额外开销。按 5% + 180 秒冷却 + 50 秒全局冷却算，
一个活跃群一天最多也就十来张；嫌多就把概率调到 `0.02`，嫌少调 `0.1`。

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 改了 `robot.env` 没生效 | `docker restart` 不重读 env_file，必须 `up -d --force-recreate`（见 2.3） |
| 群里说「画个猫」但不出图 | 看 `docker logs` 的「未触发出图」日志；或直接用 `/画图 猫` 绕过模型 |
| 出图很慢 | 生图 5~15 秒，插件已用单独消息发送、并发上限 2；调 `DSH_IMG_TIMEOUT` |
| 主模型失败 | 自动降级到 `DSH_IMG_FALLBACK` 里的备用模型 |
| 图片堆积占磁盘 | `DSH_IMG_KEEP`（默认 30 天）到期自动清理 |
| 想换画风 | 改 `DSH_IMG_STYLE`（所有图统一追加） |
| 想让机器人画自己 | 说「画你自己 / 自拍」，插件会用 `DSH_IMG_SELF` 里的形象描述 |
| 随机生图刷屏 | 调小 `DSH_IMG_RANDOM_RATE`，调大 `DSH_IMG_RANDOM_COOLDOWN` |
